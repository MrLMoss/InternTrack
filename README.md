# InternshipTracker

A Java-based internship application tracker designed to help users organize and manage their internship applications.

## Planned Features
- Add internship applications
- Update existing applications
- Delete applications
- View all applications
- Search and filter applications
- Sort applications
- Save application data locally

## Project Structure
- `Application.java` — Represents an individual internship application.
- `ApplicationManager.java` — Manages the collection of internship applications.
- `Main.java` — Entry point for interacting with the application.
- `data/` — Stores application data.
